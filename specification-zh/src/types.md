# 类型与推断

```grammar,types
Type -> TypeNoBounds

TypeNoBounds ->
      ParenthesizedType
    | TypePath
    | UnitType
    | ReferenceType
    | ArrayType

ParenthesizedType -> `(` Type `)`
```

<a id="supported-types"></a>
## 支持的类型

| 类型 | 含义 |
| --- | --- |
| `i32`, `isize` | 两种不同的有符号 32 位整数 |
| `u32`, `usize` | 两种不同的无符号 32 位整数 |
| `bool` | 布尔值 |
| 具名结构体；其声明或 impl 中的 `Self` | 名义类型的具名字段积类型 |
| `[T; N]` | 长度为受限 `usize` 常量的定长数组 |
| `&T`, `&mut T`, `&'a T`, `&'a mut T` | 共享或可变引用 |
| `()` | 函数或控制流结果 |
| [`Box<T>`, `Vec<T>`](types/heap.md) | 拥有所有权的堆对象或动态序列 |

发散表达式在内部使用 [never 类型](types/never.md)。

结构体类型是名义类型。引用、数组、`Box` 和 `Vec` 是结构类型。四种整数类型始终彼此不同。数组长度按值比较，因此 `[i32; 4]` 和 `[i32; (4usize)]` 相同。当且仅当所引用的类型和可变性匹配时，两个引用类型才相同；生命周期实参不区分引用类型，并且必须满足[生命周期有效性保证](undefined-behavior.md#lifetime-validity)。

<a id="inference"></a>
## 推断

类型推断根据初始化器补全省略的局部绑定类型。函数和条目的签名必须显式给出。每个绑定只有一个固定类型；后续使用不会改变它。在 `Box` 和 `Vec` 构造函数调用中省略显式的具体类型实参属于[未定义行为](heap.md#builtin-signatures)。字段或方法查找之前，必须已知接收者的类型。

<a id="integer-literals"></a>
### 整数字面量

整数字面量按以下顺序使用有限的推断规则：

1. 后缀确定类型。
2. 没有后缀时，如果期望类型是 `i32`、`u32`、`isize` 或 `usize` 之一，则使用该类型。
3. 否则使用 `i32`。

期望类型来自[下述上下文与传播规则](#coercion-sites-and-expected-types)。没有这样的期望时，另一个操作数、相邻数组元素或分支以及绑定的后续使用都不会决定字面量的类型。整数类型一经选定，就不会隐式改变。

```rust,ignore
let n = 1;                   // i32：无期望类型
let count: u32 = 1;          // u32：来自标注
let sum: u32 = 1 + 2;        // 未定义行为：需要通过 + 传播
let neg: isize = -1;         // 未定义行为：需要通过一元 - 传播
let r: &u32 = &1;            // 未定义行为：需要通过 & 传播
let values: [u32; 2] = [1, 2]; // u32 元素；usize 长度
let bad: u32 = 1i32;         // 编译错误：后缀确定类型
let later: u32 = n;          // 编译错误：n 已经是 i32
let mixed = 1 + 2u32;        // 编译错误：1 没有期望类型
```

数组长度和索引的期望类型是 `usize`，因此 `[i32; 4]`、`[0; 4]` 和 `data[0]` 无需后缀也有效。类型选择之后进行范围检查：值超出所选类型可表示范围的整数字面量具有[未定义行为](undefined-behavior.md#integer-literal-range)。字面量的数值大小绝不会导致选择不同的整数类型。

<a id="conversions-and-coercions"></a>
## 显式转换与强制转换

显式转换使用 `as`。强制转换是在下列某个表达式位置进行的自动调整。本节组织方式遵循 [Rust Reference](https://doc.rust-lang.org/reference/type-coercions.html)，但仅包含 Rx 支持的类型和操作。

<a id="explicit-conversions"></a>
### 显式转换

整数到整数以及布尔值到整数的转换需要 `as`。整数转换保留 32 位位模式；`false` 变为 0，`true` 变为 1。这些是唯一受支持的[显式类型转换](expressions/operator-expr.md#casts)。条件要求 `bool` 类型的表达式；整数值不能用作条件，也不会隐式转换。

<a id="coercion-sites-and-expected-types"></a>
### 强制转换位置与期望类型

**一对一强制转换**针对已知目标检查一个表达式，该目标称为它的*期望类型*。**最小上界（LUB）强制转换**为多个表达式寻找公共目标。这一区分遵循 [Rust Compiler Development Guide](https://rustc-dev-guide.rust-lang.org/hir-typeck/coercions.html)。期望整数类型可以在强制转换之前决定无后缀字面量的类型；强制转换本身不转换整数。

以下位置具有已知的期望类型，使用一对一强制转换：

| 表达式位置 | 期望类型 |
| --- | --- |
| 带标注的 `let` 初始化器 | 标注类型 |
| 常量初始化器 | 声明的常量类型，受限于受支持的[常量形式](const_eval.md) |
| 赋值右操作数 | 目标类型 |
| 函数、方法或容器构造函数实参 | 声明的形参类型；方法接收者遵循[接收者调整](expressions/method-call-expr.md#method-lookup) |
| 函数尾表达式或 `return` 操作数 | 声明的结果类型 |
| 结构体字段初始化器 | 声明的字段类型 |

期望类型穿过括号传播，传入块尾表达式、`if` 表达式的两个结果分支，以及所有以某个 `loop` 为目标的 `break` 值表达式。期望数组类型 `[T; N]` 为每个列出的或重复的元素提供 `T`，并要求长度为 `N`。每个这样的结果表达式都针对该目标检查；除下述传播排除情况外，失败属于编译错误。

传播仅通过以上列出的形式重复进行。它不穿过二元运算、一元运算或借用表达式（`&e` 和 `&mut e`），也不重新检查较早的绑定初始化器。如果程序需要通过运算符或借用表达式传播类型来确定整数字面量的类型，则其行为属于**未定义行为**，而非必须报告的编译错误。

这里排除的是对传播的依赖，而非运算符或借用本身。例如，`let n: i32 = 1 + 2;` 通过默认类型生效，`let r: &u32 = &1u32;` 则因后缀确定类型而生效。由后缀或已有绑定确定的不兼容类型仍是编译错误。即使在运算符或借用内部，调用实参仍会获得声明的期望类型。

```rust,ignore
// 期望类型 u32 传播到块尾、if 分支和 loop 的 break：
let x: u32 = { 1 };                            // 有效：1 获得期望类型 u32
let y: u32 = if true { 1 } else { 2 };         // 有效：1 和 2 获得期望类型 u32
let z: u32 = loop { break 42; };               // 有效：42 获得期望类型 u32

// 但期望类型不会穿过运算符或借用：
let a: u32 = 1 + 2;                            // 未定义行为（需要通过 + 传播）
let b: &u32 = &1;                              // 未定义行为（需要通过 & 传播）
let c: &u32 = &1u32;                           // 有效：后缀确定字面量类型
```

条件要求 `bool`，数组长度和索引的期望类型为 `usize`，循环体和没有 `else` 的 `if` 要求单元结果。运算符遵循其[操作数规则](expressions/operator-expr.md)。这些要求不会启用额外的转换。

<a id="coercion-types"></a>
### 强制转换类型

仅支持以下调整：

| 源类型 | 目标类型 | 调整 |
| --- | --- | --- |
| `T` | `T` | 保持类型；应用普通的复制/移动规则，但下述可变引用重借用除外 |
| `&mut T` | `&T` | 通过共享引用借用同一个值 |
| `&S` 或 `&mut S` | `&T` | 沿内建解引用从 `S` 到达 `T` 位置，再借用它 |
| `&mut S` | `&mut T` | 沿内建解引用从 `S` 到达可变的 `T` 位置，再可变借用它 |
| never | 任意目标 | 该路径不产生值 |

内建解引用步骤为 `&U` 到 `U`、`&mut U` 到 `U` 和 `Box<U>` 到 `U`。这些步骤可以重复，直到与目标所引用的类型完全匹配。可变目标要求最外层是 `&mut`，且路径上没有共享引用。调整会借用到达的值，而不移动其内容。`Vec` 没有内建解引用。

```rust,ignore
let mut boxed = Box::<i32>::new(1);
let r: &i32 = &boxed;           // &Box<i32> 到 &i32
let m: &mut i32 = &mut boxed;   // &mut Box<i32> 到 &mut i32
```

强制转换不会隐式借用拥有所有权的值：`Box<T>` 不能强制转换为 `T` 或 `&T`；对于后者，应写成 `&boxed`。它不会转换已存储的数组或容器元素，不会改变内部引用的可变性，也不会产生切片。例如，`&mut &mut i32` 不能强制转换为 `&mut &i32`。数组的*字面量元素*可以分别强制转换，因为它们是独立的表达式位置。

<a id="mutable-reference-reborrowing"></a>
### 可变引用重借用

> **注意**：由于我们保证生命周期有效，本项目中你无需了解重借用。此处保留这一内容仅为使规范完整。

在强制转换位置，可以将 `&mut T` 再次借用为 `&mut T`。这称为*重借用*：新借用结束后，原引用再次可用。相反，不带标注的 `let` 绑定会移动引用：

```rust,ignore
let mut x = 1;
let p = &mut x;
{
    let q: &mut i32 = p; // 重借用
    *q = 2;
}
*p = 3;
let moved = p;           // 移动
*moved = 4;
```

移动后，若不重新初始化就不能使用 `p`。将 `p` 作为实参传给 `&mut i32` 形参会以同样方式重借用它。后续使用不会把移动变为重借用。

<a id="least-upper-bound-coercions"></a>
### 最小上界强制转换

当没有期望类型确定目标时，LUB 强制转换为以下表达式寻找公共类型：

- 带 `else` 的 `if` 的结果分支。
- 数组字面量的元素。
- 所有以同一个 `loop` 为目标的 `break` 表达式的值。

存在期望类型时，这些相同的表达式使用到该固定目标的一对一强制转换。函数返回和函数尾表达式也共享一个固定目标：声明的结果类型。它们绝不会推断出不同的函数签名。

目标未知时，先独立确定各结果的类型，对没有期望整数类型的无后缀整数使用 `i32`。当前 LUB 目标不是其他结果的期望类型。按源代码顺序考察结果，并忽略能够适配任意目标的 never 结果。以第一个剩余结果的类型作为当前目标 `T`。对于之后每个类型为 `U` 的结果：

1. 如果 `U` 能强制转换为 `T`，保留 `T`。
2. 否则，如果 `T` 能强制转换为 `U`，且此前每个结果都能调整为 `U`，则使用 `U` 作为新目标，并同时调整此前的结果。
3. 否则，行为未定义（[未定义行为](undefined-behavior.md#test-guarantees)）。不要求寻找第三种公共类型。

如果所有结果都是 never，则结果类型为 never。空数组遵循[零大小数据排除规则](undefined-behavior.md#zero-sized-data)。不带值的 `break;` 提供 `()`；以嵌套循环为目标的 break 不参与。

下表每行都是独立的示例：

| 表达式 | 结果 |
| --- | --- |
| `let a = [&mut 1, &123];` | `[&i32; 2]`；第一个元素变为共享引用 |
| `let a = [&123, &mut 1];` | 相同类型；第二个元素变为共享引用 |
| `let a = [&mut 1u32, &123u32];` | `[&u32; 2]` |
| `let a = [&mut 1u32, &123];` | 未定义行为：`123` 没有期望类型，因此为 `i32` |
| `let a: [&u32; 2] = [&mut 1, &123];` | 未定义行为：推断 `u32` 需要穿过两处借用传播 |
| `let a: [&u32; 2] = [&mut 1u32, &123u32];` | 有效：字面量已经是 `u32`；第一个引用强制转换为共享引用 |
| `let a = [&mut &1, &mut &mut 2];` | 未定义行为：内部引用的可变性不同 |
| `let a: [&mut &i32; 2] = [&mut &1, &mut &mut 2];` | 编译错误：第二个元素无法满足固定的期望类型 |

这些规则确定表达式的类型；它们不改变求值顺序，也不改变独立的方法和运算符调整规则。

<a id="recursive-types"></a>
## 递归类型

按值包含的结构体或数组形成的包含环没有有限大小，属于编译错误。引用、`Box` 和 `Vec` 提供间接层，因此支持通过这些类型构成的递归和相互递归结构体。

```rust,ignore
struct Node {
    value: i32,
    children: Vec<Node>,
}
```

<details>
<summary>递归布局细节</summary>

`struct Infinite { child: Infinite }` 无效，因为 child 内联存储；内联数组同样无法打破环。在另一声明的容器（例如 `Box` 或 `Vec`）中引用无效的循环类型，不会使该循环类型定义变得有效。

```rust,ignore
// 无效：内联包含环导致无限大小
// struct BadNode { child: BadNode }
// struct BadArray { items: [BadArray; 1] }

// 有效：间接层打破布局环
struct GoodNode {
    child: Box<GoodNode>,
}
```

有限布局并不意味着可构造。`struct Chain { next: Box<Chain> }` 具有有限布局，但由于 `Box` 不可为空，不存在终止的值。这不会使其声明无效。

实现可以仅沿内联结构体和数组依赖检查环。容器 API、Trait 能力和回收在 [Box 与 Vec](heap.md) 中另行定义。

</details>
