# 条目

```grammar,items
Item -> UseDeclaration | Function | Struct | ConstantItem | Implementation
```

条目构成一个[源代码编译单元](crates-and-source-files.md)。以下章节定义了 [use 声明](items/use-declarations.md)、[函数](items/functions.md)、[结构体](items/structs.md)、[常量](items/constant-items.md)和[固有实现](items/implementations.md)。实现块成员在[关联条目](items/associated-items.md)中描述，生命周期参数列表在[生命周期参数与约束](items/generics.md)中规定。
